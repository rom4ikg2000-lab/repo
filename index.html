Пакеты

  • WiggleThemerootless + rootful
    Обои для экрана блокировки с эффектом желе и водной рябью. Реагируют на движение телефона. iOS 15–18, A12+.
  • OriginDropletrootless + rootful
    Капля на домашнем экране двигается при тряске телефона и перемещается по нажатию на пустое место.

Скачать вручную

Можно установить твики через Sileo или Zebra. Для ручной установки откройте deb-файл в Filza, нажмите Install и сделайте respring.
