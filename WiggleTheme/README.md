# WiggleTheme

«Жидкие» обои экрана блокировки в стиле **Wiggle Theme из vivo OriginOS 7** — твик на Theos с Metal-шейдером.

**Цель:** iOS 17–18, A12+, rootless-джейлбрейк (bootstrap в `/var/jb`), arm64.

## Что делает

При встряхивании или наклоне телефона обои лок-скрина ведут себя как жидкая поверхность:

- **Желе / пружина** — затухающая синусоида: амплитуда задаётся величиной последнего импульса акселерометра, направление — вектором импульса; фаза бежит и по времени, и по пространству (дрожит, а не просто сдвигается). Поверх — недодемпфированная CPU-пружина от наклона (гироскоп + attitude): обои «плывут» за наклоном и пружинят обратно.
- **Водная рябь** — радиальный волновой фронт, расширяющийся от точки импульса (смещена в направлении встряски), с гауссовым пакетом, затуханием по времени/расстоянию и **преломлением** (хроматическая дисперсия по смещённым UV).
- Режимы переключаются в настройках: **желе / рябь / оба**.
- **Alpha-маска (PNG)** — задаёшь путь, альфа-канал определяет, какие пиксели деформировать (прозрачное = нетронуто). Пусто = весь экран.
- Часы, уведомления и контролы лок-скрина лежат поверх Metal-слоя и **не деформируются**.

## Архитектура

```
CMMotionManager (60 Гц)
 ├─ userAcceleration ──► тряска? ──► impulse/dir/mag + ripple center ─┐
 ├─ rotationRate ──────► микрорывки в пружину                          │ uniforms (MTLBuffer)
 └─ attitude ──────────► цели CPU-пружины наклона ────────────────────┘
                                                                  ▼
SBFWallpaperView (хук layoutSubviews, только экран блокировки)
 └─ snapshot UIView ──► MTKTextureLoader ──► MTLTexture ──► wgFrag: смещённые UV → цвет
                                                             ▲
                                            CAMetalLayer + wgVert/wgFrag (компиляция .metal на устройстве)
```

- **Почему view-level, а не BackBoard:** обои композитятся в SpringBoard'е; подмена контента вьюхи обоев Metal-слоем — самый стабильный путь, переживает версии 15→18 без правки приватных классов рендера.
- **Почему .metal компилируется на устройстве:** Theos не умеет собирать Metal; `MTLLibrary` из исходника (`newLibraryWithSource:`) собирается за миллисекунды один раз, файл кладётся пакетом в `/var/jb/Library/Application Support/WiggleTheme/`.
- **Батарея:** датчики работают только на заблокированном экране (darwin-уведомление `com.apple.springboard.lockstate`), CADisplayLink ставится на паузу, когда все амплитуды затухли.

## Настройки (Настройки → WiggleTheme)

| Параметр | Что делает |
|---|---|
| Включено | мастер-выключатель |
| Режим | желе / водная рябь / оба |
| Интенсивность | множитель амплитуды всех деформаций (0–1) |
| Затухание | скорость затухания синусоиды импульса (0.05–0.6) |
| Реакция на наклон | сила пружинного сдвига от attitude (0–1) |
| Путь к маске | полный путь к PNG с альфа-каналом |
| Подробные логи | `[WiggleTheme]` в Console |

## Сборка (Theos в WSL/Ubuntu)

> **Важно:** команды выполняются в терминале **WSL (Ubuntu)**, не в PowerShell — `/mnt/c/...` существует только внутри WSL.
> Окружение в этой машине уже настроено: Theos в `~/theos`, SDK 16.5, ldid, тулчейн clang.
> Deployment target — 16.0: в theos/sdks нет SDK 17, но 17-only API твик не использует и на iOS 17/18 работает нормально.

```bash
# зависимости и Theos — как в ../OriginDroplet/README.md (если ещё не стоит)
cd /mnt/c/Users/SKIBIDIST/Documents/rustra1n/repo/WiggleTheme
make package FINALPACKAGE=1                                 # rootless (по умолчанию)
make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=rootful    # rootful
export THEOS_DEVICE_IP=<IP> THEOS_DEVICE_PORT=22
make install   # или .deb через Filza → Respring
# либо всё сразу (оба твика, обе схемы + apt-репо): bash ../build-all.sh
```

После респринга: заблокируй экран и встряхни телефон.

## Тюнинг констант (если хочется другой характер)

| Что | Где | Значение по умолчанию |
|---|---|---|
| Частота желе-колебаний | `WallpaperShader.metal` → `u.misc.y` (омега, из Tweak.xm) | 16 рад/с (~2.5 Гц) |
| Пространственная частота желе | `wgFrag`, `sin(proj * 22.0 ...)` | 22 |
| Скорость фронта ряби | `wgFrag`, `t * 0.85` | 0.85 uv/с |
| Ширина волнового пакета | `wgFrag`, `front*front / 0.0045` | σ ≈ 0.067 |
| Жёсткость/демпфирование пружины наклона | `Tweak.xm`, `tick:` (`120.0`, `10.0`) | ω≈11, ζ≈0.46 |
| Порог тряски | `Tweak.xm`, `motionTick:` (`0.85`) | 0.85 g |

## Если что-то не так

- **Эффекта нет.** Включи «Подробные логи», Console → фильтр `[WiggleTheme]`:
  - `shader source not found` — файл не доехал: проверь `/var/jb/Library/Application Support/WiggleTheme/WallpaperShader.metal`;
  - `MTLLibrary compile failed` — скажи текст ошибки, поправлю MSL;
  - логов `installed over ...` нет вообще — на твоём билде iOS обои не в `SBFWallpaperView`; пришли классы из лога, добавлю совместимость.
- **Обои черные/не те.** Снапшот не сработал (`snapshot failed`) — пришли версию iOS.
- **Тряска не срабатывает** — проверь, что экран заблокирован (датчики живут только на локскрине — это экономия батареи, см. архитектуру).
- **Сильно греет** — уменьши Интенсивность/реакцию на наклон; рендер сам спит в покое, но активная фаза честно рисует 60 кадров.
